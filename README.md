# 🏰 원소 타워 디펜스

> **Gemini & Claude**로 제작한 웹 기반 원소 타워 디펜스 게임입니다.  
> 4가지 원소 타워를 조합, 합성, 강화하여 몰려오는 적들과 보스를 물리쳐 보세요!

---

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Graphic / Animation**: HTML5 Canvas API (2D Context)
- **Data Persistence**: Web Storage API (`localStorage`)

---

## 🎮 게임 특징 (Key Features)

- **4가지 고유 원소 타워**:
  - 🔥 **불 (Fire)**: 범위 피해 및 지속 화염 피해
  - 🧊 **얼음 (Ice)**: 범위 피해 및 적 이동 속도 둔화
  - ⚡ **전기 (Lightning)**: 번개가 여러 적을 연속으로 공격하는 체인 라이트닝
  - ☠️ **독 (Poison)**: 강렬한 지속 중독 피해
- **타워 합성 & 레벨업 (Merge System)**:
  - 동일한 원소와 동일한 레벨의 타워를 드래그 앤 드롭으로 합성하여 더 강력한 타워(최대 Lv.5)로 진화시킬 수 있습니다.
- **원소 강화 시스템**:
  - 게임 중 획득한 골드로 각 원소의 공격력을 개별 업그레이드할 수 있습니다.
- **보스 웨이브 & 경고 연출**:
  - 10웨이브(중간 보스), 20웨이브(최종 보스) 등장 시 화면 경고 연출과 함께 강력한 보스가 출현합니다.
- **화려한 파티클 이펙트**:
  - 배경 연출, 공격 피격, 타워 소환 및 합성 시 동적인 파티클 애니메이션을 제공합니다.
- **자동 저장 (Auto Save)**:
  - `localStorage`를 활용하여 진행 중인 스테이지, 골드, 체력, 타워 배치 상태가 자동 저장되며 언제든 이어할 수 있습니다.

---

## 🕹️ 플레이 방법 (How to Play)

1. **게임 시작**: 로비 화면에서 스테이지를 선택하고 게임을 시작합니다.
2. **타워 소환**: 골드를 사용하여 맵 내 빈 그리드 타일에 무작위 원소 타워를 소환합니다.
3. **타워 합성**: 동일한 원소 및 레벨의 타워를 클릭하여 다른 타워 위로 드래그하면 한 단계 높은 레벨로 합성됩니다.
4. **원소 강화**: 우측 상단 UI에서 골드를 소비하여 특정 원소 타워의 기본 공격력을 강화합니다.
5. **웨이브 방어**: 경로를 따라 이동하는 적들이 기지에 도달하지 못하도록 처치하세요. (체력이 0이 되면 게임 오버)
